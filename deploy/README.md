# chemicalprocess.org deployment

The laboratory serves both `chemicalprocess.org` and `www.chemicalprocess.org` over HTTPS.

The checkout lives in its service account's home directory as `pfdsim`.
`pfdsim@.service` uses that account's home directory and the checkout's virtualenv,
so the maintained unit needs no machine-specific absolute paths. 

`chemicalprocess.org` is the maintained, live nginx configuration after HTTPS
activation. The installer links it through nginx's sites directories and writes
machine-specific TLS/ACME paths into system nginx snippets. 

Initial setup from the repository root:

```sh
uv sync --extra web
chmod +x deploy/renew-nginx.sh
sudo python3 deploy/install.py --phase bootstrap
```

Issue a certificate named `chemicalprocess.org` covering both hostnames with
Certbot's webroot authenticator. The installer uses the system's conventional
`var/www/html` webroot; pass its full path to Certbot's `--webroot-path` option.
TLS settings are generated by this installer and do not require files from
Certbot's nginx plugin.
Then activate HTTPS:

```sh
sudo python3 deploy/install.py --phase https
```

Certbot's existing timer renews the certificate. The linked deployment hook
checks nginx configuration and reloads it after renewal.

The service sets one trusted proxy hop and secure session cookies. Nginx replaces
`X-Forwarded-For` with the actual client address, so public clients cannot reset
guest CPU quotas by supplying their own forwarded-address header. The app uses
its normal account/autosave storage and simulator caches.

The installer keeps recoverable backups in the system configuration directory,
on the same filesystem as the installed files, and tests nginx/systemd
configuration before activation. After later application updates, restart the
service explicitly:

```sh
service_account=$(stat -c '%U' .)
sudo systemctl restart "pfdsim@${service_account}.service"
```

Systemd stops the entire service control group, including calculation workers,
so a restart cannot leave old computation workers running against newer code.
